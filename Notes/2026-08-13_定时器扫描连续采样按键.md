> 工程：`6-5PWM电机 (定时器扫描+连续采样)` | 芯片：STM32F103C8T6 | 标准库 V3.5
> 核心：不再用外部中断，改用 **SysTick 软件定时器每 5ms 扫描按键 + 状态机连续采样消抖**，实现 3 键短按/长按控制电机方向与速度。

## 一、核心知识点

### 1.1 整体架构（中断扫描 → 轮询扫描的转变）

```text
SysTick 1ms 中断
    ↓ SoftTimer_Update()
软件定时器（5ms 到点置 Flag）
    ↓ 主循环查询 Flag
Key_Scan() 每 5ms 扫描 3 个按键（状态机）
    ↓
短按/长按回调 → Motor_Direction / Motor_Speed
```

关键区别：**按键检测不在中断里做，在主循环里轮询**。中断只维护时间基准（1ms 心跳），这样中断函数极短、不阻塞，按键逻辑集中、好调试。

### 1.2 按键状态机（三态）

| 状态 | 含义 | 进入条件 | 退出条件 |
|---|---|---|---|
| 状态0 | 松开·等待按下 | 上电/松开 | 读到低电平 → 状态1 |
| 状态1 | 消抖·连续采样 | 检测到按下 | 连续3次低 → 状态2；读到高 → 回0 |
| 状态2 | 按住·区分长短按 | 消抖完成 | 按住≥1s触发长按；松开时未长按则触发短按 → 回0 |

![按键状态机](assets/按键状态机定时器扫描.svg)

### 1.3 连续采样消抖（方法三）与时间戳消抖（方法二）的对比

| 维度 | 方法二：时间戳消抖 | 方法三：定时器扫描+连续采样（本工程） |
|---|---|---|
| 采样方式 | 主循环有空就查时间差 | 固定 5ms 等间隔采样 |
| 消抖判据 | `now - Key_Time >= 20ms` | 连续 3 次读到低电平 = 15ms |
| 抗主循环抖动 | 一般 | **好**（等间隔，不受主循环繁忙影响） |
| 区分短按/长按 | 需额外计时逻辑 | 状态机天然支持（hold_count） |
| 适用 | 外部中断+时间戳 | 纯轮询、多按键 |

### 1.4 软件定时器（SysTick 多路定时器池）

```text
1 个 SysTick 1ms 中断 → 维护 N 路软件定时器（Timers[] 数组）
每路：Period（周期）+ Counter（计数）+ Flag（到点标志）
```

- 主循环 `if (Timers[i].Flag) { Flag=0; 执行任务; }`
- 新增定时任务只需在 `Systick.h` 加一个编号宏，无需新开硬件定时器

### 1.5 短按/长按区分原理

```text
消抖完成进入状态2 → hold_count 每 5ms +1
    ├─ 到 200 次（1s）且未触发过 → 触发长按回调，long_done=1
    └─ 中途松开 → long_done==0 则触发短按回调
```

核心：**长按先到先触发，短按在松开时补发**，`long_done` 保证长按只触发一次。

## 二、重要代码参考（可直接抄）

### 2.1 Systick.c —— 1ms 心跳 + 软件定时器

```c
#include "stm32f10x.h"
#include "Systick.h"

volatile uint32_t Systick_Count = 0;          /* 全局 1ms 时间戳 */
SoftTimer_TypeDef Timers[TIMER_COUNT];        /* 软件定时器池 */

void Systick_Init(void)
{
    SysTick_Config(SystemCoreClock / 1000);   /* 72MHz/1000 = 1ms 中断 */
}

void SoftTimer_Start(uint8_t idx, uint16_t period)
{
    Timers[idx].Period  = period;
    Timers[idx].Counter = 0;
    Timers[idx].Flag    = 0;
}

void SoftTimer_Update(void)   /* 在 SysTick_Handler 中每 1ms 调用 */
{
    for (uint8_t i = 0; i < TIMER_COUNT; i++)
    {
        if (++Timers[i].Counter >= Timers[i].Period)  /* 用 >= 防跳变漏判 */
        {
            Timers[i].Counter = 0;
            Timers[i].Flag    = 1;
        }
    }
}
```

### 2.2 stm32f10x_it.c —— 中断只做一件事

```c
extern void SoftTimer_Update(void);

void SysTick_Handler(void)
{
    Systick_Count++;        /* 时间戳 +1ms */
    SoftTimer_Update();     /* 更新所有软件定时器 */
}
```

### 2.3 Key.c —— 三态状态机（每 5ms 调用 Key_Scan）

```c
typedef struct
{
    GPIO_TypeDef *GPIOx;
    uint16_t      Pin;
    uint8_t       state;        /* 0=松开 1=消抖 2=按住 */
    uint8_t       count;        /* 消抖采样计数 */
    uint16_t      hold_count;   /* 按住计时（每 5ms +1） */
    uint8_t       long_done;    /* 长按已触发标记 */
    void (*ShortAction)(void);  /* 短按回调 */
    void (*LongAction)(void);   /* 长按回调 */
} Key_TypeDef;

#define LONG_PRESS_TICKS  200   /* 200次×5ms = 1s */

void Key_Scan(void)
{
    for (uint8_t i = 0; i < KEY_NUM; i++)
    {
        uint8_t level = GPIO_ReadInputDataBit(Keys[i].GPIOx, Keys[i].Pin);
        switch (Keys[i].state)
        {
        case 0:   /* 松开，等待按下 */
            if (level == RESET) { Keys[i].state = 1; Keys[i].count = 0; }
            break;
        case 1:   /* 消抖：连续3次低 */
            if (level == RESET)
            {
                if (++Keys[i].count >= 3)
                {
                    Keys[i].state = 2;
                    Keys[i].hold_count = 0;
                    Keys[i].long_done = 0;
                }
            }
            else Keys[i].state = 0;   /* 抖动/松开回0 */
            break;
        case 2:   /* 按住：区分长短按 */
            if (level == RESET)
            {
                if (++Keys[i].hold_count >= LONG_PRESS_TICKS)
                {
                    if (Keys[i].long_done == 0)
                    {
                        Keys[i].long_done = 1;
                        Keys[i].LongAction();    /* 长按只触发一次 */
                    }
                }
            }
            else
            {
                if (Keys[i].long_done == 0)
                    Keys[i].ShortAction();       /* 没长按过 → 短按 */
                Keys[i].state = 0;
            }
            break;
        }
    }
}
```

### 2.4 main.c —— 主循环查询定时器标志

```c
int main(void)
{
    Systick_Init();
    SoftTimer_Start(TIMER_KEY_SCAN, 5);   /* 按键扫描 5ms 周期 */
    OLED_Init();
    Motor_Init();
    Key_Init();

    while (1)
    {
        if (Timers[TIMER_KEY_SCAN].Flag)
        {
            Timers[TIMER_KEY_SCAN].Flag = 0;
            Key_Scan();                    /* 每 5ms 扫一次按键 */
        }
    }
}
```

## 三、今日踩的坑

| 坑 | 现象 | 原因 | 解法 |
|---|---|---|---|
| 轮询判断时间差不准 | 消抖时长飘忽 | 主循环不固定，扫描间隔抖动 | 改用**固定 5ms 定时器 + 连续采样** |
| 长按重复触发 | 按住 3 秒触发多次 | 没标记已触发 | `long_done` 标志，只触发一次 |
| 长按后松手又触发短按 | 长按+短按都执行 | 松开时没判断 long_done | 松开时 `if (long_done == 0)` 才触发短按 |
| 计数器用 `==` 漏判 | 偶尔丢一次节拍 | 中断延迟导致计数跳变 | 用 `>=` 判断到点 |
| 消抖期间读高电平就回0 | 快速点击丢失 | 抖动中途回0太激进 | 状态1 连续计数，抖动中回0是正常设计（需调整阈值） |

## 四、容易搞混的概念

### 4.1 状态机 vs 标志位

- 标志位：只有 0/1，表达"是否发生"；
- 状态机：多状态转移，表达"过程到哪一步"。按键的"松开→消抖→按住"是**过程**，用状态机更自然。

### 4.2 消抖计数 vs 按住计时

- `count`：状态1 里用，连续 3 次 = 15ms 消抖；
- `hold_count`：状态2 里用，累加到 200 = 1s 长按阈值。
两个计数器职责不同，别混用。

### 4.3 中断里 vs 主循环里做按键

| 位置 | 优点 | 缺点 |
|---|---|---|
| 中断里 | 响应快 | 中断变长、逻辑难调试、易卡死 |
| 主循环（本工程） | 逻辑集中、好调试、可扩展 | 响应延迟 = 扫描周期（≤5ms 无感） |

### 4.4 软件定时器 vs 硬件定时器

- 硬件定时器：每路独立硬件，精准，但资源有限（TIM2~TIM4）；
- 软件定时器：1 个硬件定时器（SysTick）派生 N 路"虚拟定时器"，够用且省资源，周期 ms 级足够。

### 5.2 状态机调试三步法

1. **打印状态**：OLED/串口显示 `state`、`count`、`hold_count`，看状态转移是否符合预期；
2. **单键调试**：先把 KEY_NUM 改 1，只留 KEY1，确认短按/长按都对，再开其余键；
3. **时间轴推演**：抖动 5ms、按住 300ms、松开——手推每个 5ms 节拍的状态变化，与实际 OLED 显示对照。
