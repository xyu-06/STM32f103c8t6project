# STM32F103C8T6 VS Code 工程

本目录是从原 Keil 工程复制出的 VS Code 工作区，原工程未修改。

## 使用方式

1. 用 VS Code 打开本目录：`D:\VScodeSTM项目文件夹`。
2. 安装 `Microsoft C/C++` 和 `Clang-Format`。
3. 打开 `User/main.c`，输入 `GPIO_`、`RCC_`、`TIM_` 等测试自动补全。
4. 按 `Ctrl+Shift+B`，选择“Keil：编译当前工程”。
5. Keil 仍可打开 `project.uvprojx`，用于下载和传统调试。

## 当前工程信息

- 芯片：STM32F103C8T6
- 标准库：STM32F10x Standard Peripheral Library
- Keil 路径：`D:\keil`
- 工程文件：`project.uvprojx`
- IntelliSense 宏：`USE_STDPERIPH_DRIVER`、`STM32F10X_MD`

## 注意

这是复制出来的工作区。请先确认 VS Code 补全和 Keil 编译均正常，再考虑把自己的代码迁移到这里。
