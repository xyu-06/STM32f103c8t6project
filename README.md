# STM32F103C8T6 学习工程集

STM32F103C8T6 单片机学习项目合集，使用 **STM32 标准外设库 V3.5**，开发环境为 **Keil MDK5 (ARMCC V5)**，部分工程配置了 **VS Code** 开发环境。

## 📖 工程列表

### Keil 工程（Keil_projects/）

基础章节（第 2~4 章）：工程模板、GPIO 基础

| 章节 | 工程 | 学习要点 |
|---|---|---|
| 2-1 | STM32工程模版 | 标准库工程结构、启动文件 |
| 3-1 | LED闪烁 | GPIO 输出、延时 |
| 3-2 | LED流水灯 | GPIO 多引脚控制 |
| 3-3 | 蜂鸣器 | GPIO 驱动有源蜂鸣器 |
| 3-4 | 按键控制LED | GPIO 输入、按键检测 |
| 3-5 | 光敏模块蜂鸣器 | 传感器输入检测 |
| 4 | OLED屏幕 | 模拟 I2C 驱动 OLED 显示 |

进阶章节（第 5~6 章）：中断、定时器、计数

| 章节 | 工程 | 学习要点 |
|---|---|---|
| 5-1 | 对射式红外传感器计数（阻塞消抖） | 外部中断、阻塞消抖 |
| 5-1 | 对射式红外传感器计数（时间戳的状态机消抖） | 外部中断、时间戳状态机消抖 ⭐ |
| 5-2 | 旋转编码器计数 | 正交解码计数 |
| 5-2 | 旋转编码器计数（外部中断不推荐） | 中断方案对比 |
| 6-1 | 定时器定时中断 | TIM 定时中断 |
| 6-1 | 定时器定时中断（systick最简定时） | SysTick 简单定时 |
| 6-2 | 定时器外部时钟 | TIM 外部时钟模式 |

### VS Code 工程（VSCode_projects/）

带 `.vscode` 配置的工程，可在 VS Code 中编写（自动补全）+ Keil 编译调试：

| 工程 | 说明 |
|---|---|
| 5-1 对射式红外传感器计数（时间戳的状态机消抖） | VS Code 配置版 |
| 6-3 LED呼吸灯 | PWM 输出控制 LED 亮度 ⭐ |
| 6-5 PWM电机 | PWM + 电机正反转/调速（按键控制）⭐ |

## 🛠️ 开发环境

| 组件 | 版本/说明 |
|---|---|
| 芯片 | STM32F103C8T6（Cortex-M3，64KB Flash，20KB RAM） |
| 标准库 | STM32F10x Standard Peripheral Library V3.5 |
| 编译器 | Keil ARMCC V5.06（ARM 编译器 5） |
| IDE | Keil MDK5（编译/下载/调试） + VS Code（代码编辑） |

## 🚀 使用方法

1. **Keil 方式**：用 Keil MDK5 打开任一工程的 `project.uvprojx`，编译下载即可
2. **VS Code + Keil 方式**（VSCode_projects 下工程）：
   - VS Code 打开工程文件夹，安装 Microsoft C/C++ 插件
   - `Ctrl+Shift+B` 调用 Keil 命令行编译
   - Keil 打开 `project.uvprojx` 下载调试

## ⚠️ 说明

- 各工程均包含完整标准库源码（Library/、Start/），可直接编译
- 编译产物（Objects/、Listings/、DebugConfig/）已通过 .gitignore 排除，不占用仓库空间
- 部分工程为同一章节的多种实现方案（如 5-1 两种消抖方式），可对比学习

## 📌 学习路线建议

1. 先掌握 2-1 ~ 4 章节：工程结构 + GPIO 基础
2. 学习 5 章节：外部中断 + 消抖（重点：时间戳状态机消抖）
3. 学习 6 章节：定时器 + PWM（LED 呼吸灯、电机控制）
4. 后续方向：串口通信、ADC、I2C/SPI 传感器、RTOS
